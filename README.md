# Buildora

Buildora is an online hardware shop where you can buy building materials like cement, steel, timber, roofing sheets, pipes, paint and tools.

I built it with plain HTML, CSS and JavaScript.

## What you can do on the site

- Browse products by category
- Search for a product and sort by price
- View the details of each product
- Add products to the cart and change the quantity
- Check out by filling in your details and choosing how to pay

The cart is saved in the browser, so it stays there even after you refresh the page.

## How to run it

Open the `index.html` file in any browser. That's it.

## Folders

- `css` has the styling
- `js` has the products list and the cart code
- `images` has the product photos

The photos are from Wikimedia Commons. The people who took them are listed in `images/CREDITS.md`.
